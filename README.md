# Blog de Tags HTML

Este é um projeto simples de uma página web que funciona como um blog para explicar algumas tags HTML.

## Sobre o Projeto

O objetivo deste projeto é demonstrar o uso de tags HTML básicas e como elas estruturam uma página web. A página contém exemplos práticos de tags com suas respectivas explicações.

## Tecnologias Utilizadas

- HTML5

## Como Usar

1. Baixe ou clone este repositório:
   ```sh
   git clone https://github.com/seu-usuario/blog-html.git
   ```
2. Abra o arquivo `index.html` no seu navegador.

## Tags HTML Abordadas

Abaixo estão algumas das tags HTML explicadas no projeto:

### 1. `<h1>` a `<h6>` - Títulos
Usadas para definir títulos e subtítulos.
```html
<h1>Título Principal</h1>
<h2>Subtítulo</h2>
```

### 2. `<p>` - Parágrafos
Usada para definir parágrafos de texto.
```html
<p>Este é um parágrafo de exemplo.</p>
```

### 3. `<a>` - Links
Usada para criar links para outras páginas.
```html
<a href="https://www.exemplo.com">Visite o site</a>
```

### 4. `<img>` - Imagens
Usada para exibir imagens na página.
```html
<img src="imagem.jpg" alt="Descrição da imagem">
```

### 5. `<ul>`, `<ol>`, `<li>` - Listas
Usadas para criar listas ordenadas e não ordenadas.
```html
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

<ol>
  <li>Item 1</li>
  <li>Item 2</li>
</ol>
```
