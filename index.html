Tags HTML

HTML (HyperText Markup Language) é a linguagem de marcação usada para criar páginas da web. Ele estrutura o conteúdo da página usando tags (como a tag "p" para parágrafos, "h1" para títulos e "img" para imagens).

Tags HTML mais comuns

Aqui estão algumas das tags HTML mais comuns:

  • title na head - titulo da aba da página
  • p - Tag para parágrafos
  • h1 a h6 - Para titulos
  • a - Para links
  • ul e li - Para listas
  • img - Para imagens

Exemplo de código HTML

Aqui está um exemplo de código HTML que cria uma página simples com um título, um parágrafo e uma imagem: 

        
            <!DOCTYPE html>
            <html>
            <head>
                <title> Minha Página </title>
            </head>
            <body>
                <h1> Bem-vindo à minha página! </h1>
                <p> Esta é uma página simples criada com HTML. </p>
                <img src="imagem.jpg" alt="Uma imagem">
            </body>
            </html>

Conclusão

HTML é a linguagem de marcação usada para criar páginas da web. Ele usa tags para estruturar o conteúdo da página e é uma parte fundamental do desenvolvimento web.
